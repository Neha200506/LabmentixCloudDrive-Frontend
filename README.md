# NEXORA DRIVE
### Cloud-Based File Management and Sharing System

## About the Project

**Nexora Drive** is a cloud-based file management and sharing application that allows users to securely store, organize, access, edit, download, and share files. It provides a user-friendly Google Drive-style interface for managing files and folders from desktop and mobile devices.

## Key Features

- User Signup, Login and Google Login
- Password recovery and reset
- File and folder management
- Drag-and-drop file upload
- File preview and DOCX document editing
- Search, filtering and sorting
- Grid View and List View
- File sharing with Viewer, Editor and Owner permissions
- Public sharing links
- Recent and Starred files
- Trash with restore and permanent delete
- File version history and restoration
- Storage management
- Mobile responsive design

## Technology Stack

- React + Vite
- Tailwind CSS
- Node.js + Express.js
- PostgreSQL / Supabase
- Supabase Storage
- JWT Authentication
- Google OAuth
- Nodemailer
- Vercel
- Git & GitHub

## System Architecture

**User → React/Vite Frontend → Node.js/Express Backend → PostgreSQL & Supabase Storage**

## Security

The application uses JWT authentication, Google OAuth, protected APIs, secure signed URLs, sharing permissions, and environment variables for sensitive credentials.

## Testing

The application was tested across authentication, file management, search, filtering, sorting, sharing, permissions, public links, Trash, version history, document editing, downloading, and mobile responsiveness.

## Deployment

The application was successfully deployed online using Vercel, with separate deployments for the frontend and backend.
